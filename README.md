# Lampa — Кинопоиск рейтинг

Плагин для [Lampa](https://lampa.stream): заменяет рейтинг TMDB на карточках фильмов
рейтингом Кинопоиска. Для фильмов без рейтинга TMDB — создаёт бейдж с рейтингом
Кинопоиска. Цвета как на Кинопоиске: 7 и выше — зелёный, ниже 7 — светло-серый.

## Установка

1. Lampa → **Настройки → Плагины → «+»**
2. Вставить URL:

   ```
   https://rusdenius.github.io/lampa-kp-rating/kp-rating.js
   ```

3. Перезапустить Lampa.

## Настройки (Настройки → Кинопоиск)

| Параметр | Описание |
|---|---|
| Источник API | `kinopoisk.ru` — официальный GraphQL, ключ не нужен (по умолчанию); `kinopoiskapiunofficial.tech` и `api.poiskkino.dev` — по своему API-ключу |
| API-ключ | только для keyed-источников |
| Заменять рейтинг TMDB | выключить — плагин ничего не меняет |
| Также на странице фильма | по умолчанию выключено (страницу фильма обычно закрывает другой плагин рейтингов) |
| Цвета Кинопоиска | зелёный 7+, серый ниже 7 |
| Отладка (лог в консоль) | подробный лог в консоль веб-версии |
| Очистить кеш рейтингов | сброс кеша (TTL: 30 дней для найденных, сутки для «не найдено») |

## Как работает

- `request_secuses` (событие Lampa, синхронно до отрисовки): значения из кеша
  подставляются в данные — карточку рисует штатный шаблон уже с Кинопоиском.
- Карточки без кеша: фоновый поиск в API, затем допатчивание уже отрисованных
  бейджей (сопоставление карточки с фильмом по названию и году); при отсутствии
  бейджа (нет рейтинга TMDB) — создание его в том же виде, что и нативный рендер.
- Карточки из внутреннего кеша Lampa (когда сетевое событие не срабатывает) —
  поиск по названию и году из `card_data` (у сериалов заголовок в DOM пуст),
  фолбэк — DOM; экраны с пакетной вставкой карточек одним узлом («Избранное»)
  обходятся рекурсией наблюдателя.
- Общая база рейтингов по годам (`data/<год>.json` на GitHub Pages): файл года
  грузится один раз за сессию, попадание отдаётся мгновенно без запроса к
  Кинопоиску; промах — обычный suggest-поиск. База авторитетна: её значение
  перезаписывает локальный кеш и ответ suggest (лечит ошибочные записи старых
  версий и коллизии названий). Коллизии в самой базе (два фильма с одним
  названием в одном году) решает сборщик: приоритет записи с рейтингом.
- Нормализация названий унифицирует ё→е — ключи базы и кеша совпадают,
  как бы ни писалось название в TMDB/Кинопоиске.
- Кеш в `localStorage` (префикс `kpr15_`), до 3 параллельных запросов, таймаут 8 с.

## Обновление базы

Каталог Кинопоиска (все фильмы по годам) обходит `tools/kp_crawl.py`
(официальный GraphQL каталога, чекпоинты по годам — переживает перезапуск),
собирает в файлы годов `tools/kp_assemble.py` (`data/<год>.json` + `manifest.json`).

Расписание (планировщик Windows, задачи на этом ПК):

| Задача | Период | Что делает |
|---|---|---|
| `KpRatingRefreshRecent` | раз в 3 дня, 05:00 | пересбор последних 3 лет → пуш |
| `KpRatingRefreshFull` | раз в год, 2 декабря | полный пересбор всей базы → пуш |

Ручной запуск: `py tools\kp_refresh.py recent` или `full` (лог: `tools/refresh.log`).

## Ограничения

- В браузерной (не Android) версии Lampa источник `kinopoisk.ru` может получать 403
  от GraphQL Кинопоиска (CORS/Origin) — используйте keyed-API там.
- Поиск фильма — по названию и году (title+year matching); редкие неоднозначные
  совпадения пропускаются, чтобы не показывать чужой рейтинг.
